#   Virtualization:
    Virtualization is a technology that virtualizes hardware. It lets multiple operating systems run on the same physical machine by using a hypervisor. Each VM has its own kernel and thinks it owns the hardware.

#   Containerization 
    Containerization is a method built on OS-level isolation. It packages an application and its dependencies while sharing the host kernel.

# Containerization & Virtualization
    hardware isolation vs application isolation. That is why they complement each other instead of competing.
